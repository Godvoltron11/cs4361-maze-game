# cs4361-maze-game

3D first-person maze game in Java + JOGL. CS 4361 Team 3 — Radhika S, Sameer V, Hudson D, Youssef H.

## Setup

`.classpath` expects `lib/jogamp-fat.jar`. Jars are gitignored, so drop the JOGL
fat jar into `lib/` after cloning or Eclipse will not resolve `com.jogamp.*`.

Run `MazeGame.main`.
